# Room Rental System

Application web de gestion et réservation de chambres en cours de développement.

## Description

Room Rental System est une plateforme permettant :

- la gestion des chambres
- la réservation en ligne
- la gestion des utilisateurs
- l’authentification sécurisée
- la gestion des profils
- l’administration des locations

Le projet est actuellement en phase de développement.

---

## Technologies utilisées

### Frontend
- React.js
- HTML / CSS / JavaScript

### Backend
- Spring Boot

### Base de données
- MySQL
